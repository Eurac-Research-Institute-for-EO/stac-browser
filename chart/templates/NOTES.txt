STAC Browser has been deployed.

{{- if .Values.ingress.enabled }}

It should be reachable at:
{{- range $host := .Values.ingress.hosts }}
  {{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
  {{- end }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}

Get the application URL by running:
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "stac-browser.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo "http://$NODE_IP:$NODE_PORT"
{{- else if contains "LoadBalancer" .Values.service.type }}

Get the application URL once the LoadBalancer IP is available:
  kubectl get --namespace {{ .Release.Namespace }} svc -w {{ include "stac-browser.fullname" . }}
{{- else }}

Port-forward to reach it locally:
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "stac-browser.fullname" . }} 8080:{{ .Values.service.port }}
  Then open http://127.0.0.1:8080{{ .Values.probePath }}
{{- end }}

Reminder: catalogUrl and other SB_* options are set under `.Values.config`.
pathPrefix / historyMode are build-time only and require rebuilding the image.
